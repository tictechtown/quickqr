# QuickQR

Instant QR Code generator. Fast, lightweight, and fully client-side.

## Live Demo

[quickqr-1q6.pages.dev](https://quickqr-1q6.pages.dev/)

## Local Run

There is no build step.

- Open `index.html` directly in your browser, or
- Serve the folder with a static server (any lightweight option works).

## Contributing

PRs and issues are welcome.

- Keep it fast and dependency-light.
- Test changes by opening `index.html` in a browser.
- Prefer small, focused PRs with a short description of the change.

## Libraries

- [PicoCSS](https://picocss.com/) (CDN) for styles
- [QRious](https://github.com/neocotic/qrious) (CDN) for QR code generation
